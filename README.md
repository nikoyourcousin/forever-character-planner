# Forever Character Planner

Планировщик состава для World of Warcraft: Forever. Помогает решить, каких персонажей создавать и как закрыть профессии, банки и аукцион. Работает в браузере, без сервера.

Уровень до 60. Две основные профессии и все дополнительные. Расы и классы соответствуют Forever. Интерфейс на русском и английском.

## Возможности

- Состав по фракциям: один мейн у Альянса и один у Орды.
- Раса, класс и профессии выбираются иконками.
- Назначения: мейн, альт, рейд, подземелья, PvP, профессии, фарм, банк, аукцион, прокачка.
- Сервер: PvE, PvP, RP, Hardcore.
- Покрытие профессий. Если в составе есть обе фракции, иконка делится пополам: слева Альянс, справа Орда. Если фракция одна, иконка просто цветная или серая.
- Поиск и фильтры по фракции и назначению.
- Список хранится в этом браузере. Его можно выгрузить и загрузить файлом `fcp-roster.json`.
- Фон меняется раз в день. Картинки лежат в `public/wallpapers`.

## Запуск

Нужен Node.js 18 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Обычно это http://127.0.0.1:5173/.

## Сборка

```bash
npm run build
npm run preview
```

Готовые файлы появятся в `dist`.

## Обои

Положите jpg, png или webp в `public/wallpapers` и обновите страницу. В режиме разработки новый файл подхватывается сам. В собранной версии список фиксируется на момент `npm run build`.

## Данные

Состав записывается в `localStorage` под ключом `fcp-roster-v1`. Очистка данных сайта в браузере удаляет список. Экспорт сохраняет копию в файл.
